3. JAVASCRIPT (Added before </body> tag)
================================================================================

A complete device detection and banner initialization system that:

- Detects device type (iOS, iPad, Android, TV, Web)
- Loads platform-specific banner content
- Creates action buttons with appropriate links
- Handles dismissal with session storage
- Initializes on DOM ready or page load

Key Functions:
✓ detectDevice() - Identifies the user's platform
✓ getBannerConfig() - Returns customized content per platform
✓ initBanner() - Sets up the banner on page load

================================================================================
CUSTOMIZATION
================================================================================

To change download links:
- Find getBannerConfig(device) function
- Modify the 'url' field in each platform config
- Example: {label:'📱 Download VLC', url:'YOUR_CUSTOM_URL', target:'_blank'}

To change banner text:
- Modify 'title' and 'desc' fields in getBannerConfig
- Each platform has its own config object (ios, android, ipad, tv, web)

To change colors:
- Use existing CSS variables: --blue, --green, --pink, --line, --muted, --ink
- Or modify the specific .banner-* CSS rules
